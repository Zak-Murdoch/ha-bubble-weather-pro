## [1.0.0] - 2026-07-19

### Added
- Initial public release of Bubble Weather Pro as a standalone Bubble Card module
- Animated, condition-aware weather icons
- Dynamic weather backgrounds tied to current condition and time of day
- Current conditions panel (temperature, feels-like, condition text)
- Hourly forecast strip (configurable number of hours)
- Daily forecast list (configurable number of days)
- Sunrise / sunset display
- First light / last light (civil twilight) display
- Moon phase display with optional dedicated moon entity, with calculated fallback
- Wind speed and direction
- Humidity display
- Rain probability display
- Fully responsive layout for desktop, tablet, and mobile
- Native Bubble Card "Import module" support via raw GitHub URL
- Full documentation set: installation, configuration, troubleshooting, FAQ
- Example dashboards: minimal, simple, Apple Weather–style, full dashboard, compact mobile
- GitHub community health files: Contributing guide, Code of Conduct, Security policy
- Issue and pull request templates
- CI workflows for Markdown lint and YAML validation
